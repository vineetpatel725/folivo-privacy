# Folivo — privacy policy

The privacy policy for **Folivo** (`com.folivo.folivo`), an offline-first document
workspace for Android.

Published at **<https://vineetpatel725.github.io/folivo-privacy/>**, which is the URL
given to the Google Play listing.

## Why this repository exists

It holds one document, and it is public so that the policy can be read by anyone
without a GitHub account — which is what Google Play requires of a privacy policy URL.
Folivo's own source lives in a private repository.

## Keeping it honest

`index.md` is a copy of `docs/PRIVACY_POLICY.md` in the Folivo repository, which is the
file the app itself bundles and renders under Settings → Privacy policy. **The two must
change together.** If they ever disagree, the copy inside the app is the one that
describes the installed build, and this one is wrong.

Every claim in it was verified against the application source rather than written from
intent.
